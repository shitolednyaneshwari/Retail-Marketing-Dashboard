# Retail Marketing Dashboard | Power BI
## 📊 Project Overview
This project is a Retail Marketing Dashboard created using Microsoft Power BI.
The dashboard provides useful insights into sales, orders, profit, customers, brands, store performance, product categories, regions, and customer segments.
## 🎯 Objectives
- Analyze retail sales data
- Track total sales and profit
- Understand monthly sales trends
- Analyze category-wise sales
- Identify top-performing brands
- Compare store performance
- Analyze customer segments
- Monitor profit margin
- Create interactive Power BI visualizations
## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analytics
## 📈 Key Dashboard Features
- Total Sales
- Total Orders
- Total Profit
- Total Customers
- Profit Margin %
- Monthly Sales Trend
- Category Wise Sales
- Sales by Region
- Top 10 Brands
- Top 10 Store Names
- Sales by Customer Segment
- Detailed Sales Table
